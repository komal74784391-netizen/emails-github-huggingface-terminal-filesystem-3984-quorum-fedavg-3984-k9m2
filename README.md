# quorum-fedavg

Reference implementation for *Quorum: Bandwidth-Aware Federated Averaging*
(ICML 2026).

Released under the BSD-3-Clause license. The client scheduler, the aggregation
server and the simulation configs are included.

## Layout

- `src/quorum/` — scheduler and aggregator
- `configs/` — simulation configurations
- `experiments/` — simulation drivers
- `data/` — synthetic fleet definitions
